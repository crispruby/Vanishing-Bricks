# Vanishing Bricks
A Unity‑built 2D brick‑breaker arcade game where you control a paddle to keep the ball in play, clear bricks, and chase the highest score. When the ball hits a brick, the brick instantly vanishes, creating a fast and satisfying gameplay loop.

## Gameplay Overview 🚀
Vanishing Bricks is inspired by classic brick‑breaker games. Your goal is to prevent the ball from falling off the bottom of the screen while using it to destroy bricks and earn points. Each time the ball hits a brick, the brick disappears immediately — giving the game its name. When all bricks are cleared, a new set appears, allowing you to continue building your score. The Best Score is tracked and displayed at the top of the screen.

## Controls 🎮
A / D — Move paddle left or right

Left / Right Arrow Keys — Move paddle left or right

Ball — Automatically bounces; use it to hit and vanish bricks

## Features ✨
Vanishing Bricks includes responsive paddle movement, simple but satisfying ball physics, and a looping brick‑respawn system that keeps the action continuous. The instant‑vanish mechanic makes each hit feel rewarding, and the persistent Best Score encourages players to improve over time.
